Privacy Policy

Last updated: November 18, 2026

Home Dashboard is a private, non-commercial display that family households run on their own Raspberry Pi (see home page). Each household installs its own copy and signs in with its own Google account. This policy explains what the app does with Google user data.

What it accesses

With the account owner's permission, it requests read-only access to:

  • Google Calendar events (calendar.readonly)
  • Google Tasks (tasks.readonly)

It cannot create, change or delete anything in Google Calendar or Google Tasks.

How the data is used

A household's events and tasks are shown only on that household's own screen. They go directly from Google to that household's device, are held only in the device's memory while it runs, and are refreshed every few minutes.

The app's developer does not receive, see or store any household's Google data. Each household's data stays between Google and that household's device.

Sharing

Google user data is not sold, shared with or transferred to anyone (including the developer or other households), not used for advertising, and not used to train AI or machine-learning models. There is no central server or database.

Storage and deletion

The only thing stored is the sign-in token, on that household's own device. Deleting the app from the device deletes it. Access can also be removed at any time at myaccount.google.com/permissions, which stops all access immediately.

Limited use

Home Dashboard's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
