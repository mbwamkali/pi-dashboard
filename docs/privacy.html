Privacy Policy

Last updated: November 18, 2026

Home Dashboard is a private display for one household (see home page). This policy explains what it does with Google user data.

What it accesses

With the account owner's permission, it requests read-only access to:

  • Google Calendar events (calendar.readonly)
  • Google Tasks (tasks.readonly)

It cannot create, change or delete anything in Google Calendar or Google Tasks.

How the data is used

Events and tasks are shown on the household's own screen and nowhere else. They are held only in the memory of the device on the home network while it runs, and refreshed every few minutes.

Sharing

Google user data is not sold, shared with or transferred to anyone, not used for advertising, and not used to train AI or machine-learning models. There is no external server or database.

Storage and deletion

The only thing stored is the sign-in token, on the device itself. Access can be removed at any time at myaccount.google.com/permissions, which stops all access immediately.

Limited use

Home Dashboard's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
